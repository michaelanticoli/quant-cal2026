# Quantumelodic Calendar Generator 2026 🎵

## Quick Start
1. Place your CSV files in the `data/` folder:
   - Rename your events file to: `astrological_events_2026.csv`
   - Rename your voids file to: `moon_voids_2026.csv`

2. Run the generator:
```bash
   python main.py
```

3. Find your calendar in `output/Quantumelodic_2026_Calendar.ics`

4. Import into any calendar app!

## Features
- ✨ Rich poetic narratives for each event
- 🎼 Musical metaphors and cosmic imagery
- 📅 Professional ICS format
- 🌙 Includes Moon void periods
- 💫 Consumer-ready with emojis

## Data Format
Your CSV files need these columns:
- **Events**: Position, Date, Time, Event
- **Voids**: Position, Date, Time, Event Description

That's it! The system handles everything else.
